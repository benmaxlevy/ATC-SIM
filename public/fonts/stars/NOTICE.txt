ATC-SIM modifications, 2026-10-08:
Converted occupied bitmap cells into exact orthogonal TrueType contours;
added Unicode aliases, font naming/metrics tables, and WOFF2 compression.
No smoothing, resampling, or reconstructed vendor artwork.
These are fonts converted from Vice's STARS bitmaps. No original vendor
provenance, official STARS font authorization, or NAS compatibility is claimed.

Corresponding source is provided alongside these fonts:
  corresponding-source.zip
The archive contains unmodified pinned bitmap definitions, the complete Go AST
export JSON, conversion/verification scripts, exact dependency pins, licenses,
and regeneration instructions. The working converter directory is not retained.
Regenerate from the ATC-SIM repository root: npm run fonts:regenerate
The command extracts source to a temporary directory and cleans it automatically.
